# Current Priorities

This page outlines the key areas we're focusing on most actively, but priorities
can change quickly based on:

1. **Our vision** — What we think needs to happen next.
2. **Real-world use cases** — Where people are getting stuck.
3. **User feedback** — What people are saying about their experience.

**This page should not be treated as a fixed roadmap.** It's a flexible snapshot
of what's currently important.

:::note
Bug fixes, general improvements, and smaller features aren't listed here. They
remain ongoing priorities.
:::

## Immediate Priorities

| Feature                  | Description                                                                   |

| **Basic SEO** | Baseline SEO controls.        |
| **SRCSET Support**          | Full SRCSET support for images.   |
| **404 Routing**   | Custom 404 error pages. |

## Community Feedback

We actively monitor user feedback and feature requests to keep our priorities
aligned with what matters most. If you have suggestions or encounter issues,
please let us know so we can incorporate that feedback into our plans.
