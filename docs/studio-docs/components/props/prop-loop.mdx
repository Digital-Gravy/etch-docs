# Data Source Prop

A Data Source prop lets a component receive a value from a data source. Each
instance can use a different source, while sharing the same structure and
styling. The value can be an array, object, or scalar; a loop needs an array.

## Set up the prop

1. Create a [data source](../../data-sources/README.md) that returns an array
   for this example, such as `[{"title": "Yoga"}, {"title": "Design"}]`.
2. In the component editor, add a **Data Source** prop and give it a name and
   key, such as `items`.
3. Optionally select a default data source for the prop.
4. To map the prop visually, hover over its icon, select **Map Property**, then
   click the element to wrap in a loop. Map the loop's item fields separately.
   Alternatively, write the loop in the HTML editor:

```html
{#loop props.items as item}
  <article>
    <h2>{item.title}</h2>
  </article>
{/loop}
```

This example displays “Yoga” and “Design”. Use fields that exist in the selected
source's data; the Data Manager preview shows its resolved value. An empty
array displays no items; a missing or non-array value cannot initialize the loop.

## Choose a source for an instance

Select the component on a page, then choose a data source in its **Data Source**
prop. Each instance can use a different source. Clearing an instance value
returns it to the component's default.

The picker inserts a braced expression such as `{data('courses')}` as the prop
value. You can also type a dynamic expression, such as `{item.courses}` when the
component is inside a loop. An unbraced `data('courses')` is treated as text,
not evaluated as a data source.

## Loop target syntax

The prop value and the loop target use different syntax: the prop value above is
wrapped in braces, but the loop target is already inside the loop's braces.

- **Incorrect:** `{#loop {props.items} as item}{/loop}` — extra braces.
- **Correct:** `{#loop props.items as item}{/loop}`.

Component prop keys use letters, digits and underscores, not dashes. For a
data item's field containing a dash, use bracket notation instead:
`{item['course-title']}`.

## Limit the items with a modifier

Use the [slice modifier](../../dynamic-data/dynamic-data-modifiers/basic-modifiers)
on the prop to display only the first three items:

```html
{#loop props.items.slice(0, 3) as item}
  <article>
    <h2>{item.title}</h2>
  </article>
{/loop}
```

For an item field containing a dash, bracket notation also works inside the loop:

```html
{#loop props.items.slice(0, 3) as item}
  <p>{item['course-title']}</p>
{/loop}
```

These examples limit what the component displays; they don't change the data
source itself.
