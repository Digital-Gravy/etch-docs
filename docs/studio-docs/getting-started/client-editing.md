# Client Editing

Client editing lets clients update content in Etch Studio without needing access
to the builder's design and code tools. A workspace owner can invite a client
and choose which websites they can open.

## Invite a client

Only the workspace owner can invite members.

1. Open your workspace dashboard and select **Members** in the sidebar.
2. Select **Invite member** and enter the client's email address.
3. Under **Role**, choose **Client**.
4. Under **Websites**, choose the websites they may open, or select **Every
   website** to include websites created later. At least one choice is required.
5. Select **Send invite**.

The client receives an email with a link to join the workspace. They can sign
in with the invited email address or set a password to create an account, then
select **Join workspace**. Pending invitations appear on the Members page,
where the owner can resend or revoke them.

To change a member's role or website access later, select **Edit access** next
to that member on the Members page.

## Edit content

Open an assigned website and select the page to edit. Clients can:

- Edit page text directly on the canvas.
- Select a link to change its text or destination.
- Select an image to replace it or update its alt text.
- Select an SVG icon to replace it from the media library. The library opens
  with an SVG filter, which can be cleared.
- Select a component to edit the properties made available for that instance.
- Create, edit and duplicate items in the Content Hub, and upload media.
- Save and publish changes when the website is set up for publishing.

Content rendered inside a loop cannot be edited directly on the canvas. Edit
the underlying content in the Content Hub when it comes from a content item.

## What stays with the rest of the team

The client builder does not offer controls to add, delete, duplicate, move, or
copy and paste page elements. Clients cannot use the code and design panels,
edit component definitions, delete Content Hub items, manage content types or
templates, or access the design and route managers and project settings.
Etch Connector is not currently available to clients.

New Content Hub items can be created, but clients cannot add page elements to
an empty page in the builder. A client can duplicate an existing item to start
from its content.
